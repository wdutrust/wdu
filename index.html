Project Nature & Scope

Projektcharakter & Umfang

طبيعة المشروع ونطاقه

WDU Trust Token exists as a live, publicly verifiable example of a minimal and immutable BEP-20 implementation. The project prioritizes clarity of on-chain behavior, absence of hidden functions, and the ability for any observer to independently confirm supply, transfers, and holder distribution through standard blockchain explorers. No financial product features, no promotional claims, and no administrative override mechanisms are present.

WDU Trust Token existiert als lebendiges, öffentlich überprüfbares Beispiel einer minimalen und unveränderlichen BEP-20-Implementierung. Das Projekt priorisiert Klarheit des On-Chain-Verhaltens, Abwesenheit versteckter Funktionen und die Möglichkeit für jeden Beobachter, Angebot, Transfers und Inhaberverteilung unabhängig zu bestätigen.

يوجد رمز WDU Trust كمثال حي وقابل للتحقق علنًا لتطبيق BEP-20 بسيط وغير قابل للتغيير. يعطي المشروع الأولوية لوضوح السلوك على السلسلة وغياب الوظائف المخفية وقدرة أي مراقب على تأكيد العرض والتحويلات وتوزيع الحاملين بشكل مستقل.

What is WDU Trust Token?

Was ist der WDU Trust Token?

ما هو رمز WDU Trust؟

WDU Trust Token (symbol: WDU) is a standard BEP-20 token deployed on the BNB Smart Chain mainnet. It features a permanently fixed total supply of exactly 700,000,000,000,000 WDU (700 trillion), minted once at deployment. The contract implements only the required BEP-20 interface functions (transfer, transferFrom, approve, allowance, balanceOf, totalSupply, name, symbol, decimals). No mint, burn, tax, fee, reflection, pause, blacklist, freeze, or upgradeable proxy logic exists. The contract is immutable and the source code is verified on BscScan as of December 18, 2025.

WDU Trust Token (Symbol: WDU) ist ein standardmäßiger BEP-20-Token, der auf dem BNB Smart Chain Mainnet bereitgestellt wurde. Er verfügt über ein dauerhaft festes Gesamtangebot von genau 700.000.000.000.000 WDU (700 Billionen), das einmalig beim Deployment gemintet wurde. Der Vertrag implementiert ausschließlich die erforderlichen BEP-20-Schnittstellenfunktionen. Es gibt keine Mint-, Burn-, Steuer-, Gebühren-, Reflection-, Pause-, Blacklist- oder Upgrade-Logik. Der Vertrag ist unveränderlich und der Quellcode ist seit dem 18. Dezember 2025 auf BscScan verifiziert.

رمز WDU Trust (الرمز: WDU) هو رمز BEP-20 قياسي تم نشره على الشبكة الرئيسية لـ BNB Smart Chain. يتميز بإجمالي عرض ثابت بشكل دائم يبلغ بالضبط 700,000,000,000,000 WDU (700 تريليون)، تم سكه مرة واحدة عند النشر. ينفذ العقد فقط وظائف واجهة BEP-20 المطلوبة. لا يوجد منطق mint أو burn أو ضريبة أو رسوم أو reflection أو pause أو blacklist أو proxy قابل للترقية. العقد غير قابل للتغيير والكود المصدري تم التحقق منه على BscScan اعتبارًا من 18 ديسمبر 2025.

Why It Exists

Warum es existiert

لماذا يوجد

The project was created to provide a clean, observable reference implementation of a fixed-supply BEP-20 token on a public blockchain. It demonstrates how total supply can be permanently capped, how standard transfer and approval mechanics operate without additional layers, and how full public verifiability of balances and events can be maintained. The design intentionally excludes all non-essential features so that observers can study pure BEP-20 behavior in a live mainnet environment.

Das Projekt wurde geschaffen, um eine saubere, beobachtbare Referenzimplementierung eines BEP-20-Tokens mit festem Angebot auf einer öffentlichen Blockchain bereitzustellen. Es demonstriert, wie das Gesamtangebot dauerhaft begrenzt werden kann, wie Standard-Transfer- und Genehmigungsmechanismen ohne zusätzliche Schichten funktionieren und wie die vollständige öffentliche Überprüfbarkeit von Salden und Ereignissen aufrechterhalten werden kann.

تم إنشاء المشروع لتوفير تنفيذ مرجعي نظيف وقابل للملاحظة لرمز BEP-20 ثابت العرض على سلسلة بلوكشين عامة. يوضح كيف يمكن تحديد إجمالي العرض بشكل دائم، وكيف تعمل آليات التحويل والموافقة القياسية دون طبقات إضافية، وكيف يمكن الحفاظ على التحقق العام الكامل من الأرصدة والأحداث.

How It Is Used

Wie es verwendet wird

كيف يتم استخدامه

WDU tokens can be transferred between any compatible BEP-20 wallets using standard transfer or transferFrom calls. Approvals can be set and checked via the approve and allowance functions. All activity is permanently visible on BscScan. There are no special access controls or privileged roles that can alter balances outside of ordinary transfers. Users interact with the token solely through the public interface defined by the BEP-20 standard.

WDU-Token können zwischen allen kompatiblen BEP-20-Wallets über standardmäßige Transfer- oder transferFrom-Aufrufe übertragen werden. Genehmigungen können über die Funktionen approve und allowance gesetzt und überprüft werden. Alle Aktivitäten sind dauerhaft auf BscScan sichtbar. Es gibt keine speziellen Zugriffskontrollen oder privilegierte Rollen, die Salden außerhalb gewöhnlicher Transfers ändern können.

يمكن تحويل رموز WDU بين أي محافظ BEP-20 متوافقة باستخدام استدعاءات transfer أو transferFrom القياسية. يمكن تعيين الموافقات والتحقق منها عبر وظيفتي approve و allowance. جميع الأنشطة مرئية بشكل دائم على BscScan. لا توجد عناصر تحكم وصول خاصة أو أدوار مميزة يمكنها تغيير الأرصدة خارج التحويلات العادية.
